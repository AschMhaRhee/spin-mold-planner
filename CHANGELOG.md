# Changelog

## 0.1.0 — first public version
- Plan a mold: STL import, balanced symmetric layout for 7–12" molds, gates into the thickest section, gate/main/point vents with zig-zag channels or drill-through, weights and pour estimate, cut list, image export.
- Explanations for every placement, gate and vent, on the drawing and in saved images.
- Zoom and pan on all drawings.
- Fix a mold: paint the short fill, get a cause, vent spots, the vent → top-gate → enlarge fix order, and a better gate if needed.
- Editable metal profiles: lead-free pewter, zinc spin alloy, Zamak 3, lead.
- Works offline as a single HTML file.
